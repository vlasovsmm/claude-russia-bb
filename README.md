# Claude Russia для bb

Собрано из закрытого репозитория, правки здесь затрутся следующим выпуском.

Поставить: в bb слева Plugins, стрелка рядом с New plugin → Install from source, адрес `https://github.com/vlasovsmm/claude-russia-bb`. Инструкция со снимками, и как открыть bb с телефона: https://docs.google.com/document/d/1JJBO0eaHe3y5ryfHIUgDX0UTQ11-lTnT9Hh4dfDzCR4/edit
Остальные три плагина «Claude Russia» поставит сам. Войти — кнопкой в меню bb, вход подтверждается на app.claude-russia.ru.
